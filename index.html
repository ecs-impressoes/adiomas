# Álbum Digital Profissional Editor de álbuns A4/A5 com posicionamento livre das fotos. 100% offline, roda direto no navegador. **[Demo Online](https://seuusuario.github.io/album-digital/)** ## Recursos - Canvas livre: arraste, redimensione, gire fotos - A4/A5 Vertical/Horizontal - Capa + páginas ilimitadas + contracapa - Upload múltiplo + bandeja de fotos - Templates: Grade 2x2, 3 colunas, destaque - Exportar PDF completo com 1 clique - Auto-save a cada 5s - Exportar/Importar projeto .json - Atalhos: Del, Ctrl+S, Ctrl+D - Fotos sem corte: object-fit contain ## Deploy GitHub Pages 1. Fork ou clone este repo 2. Settings > Pages > Deploy from branch > main / root 3. Acesse https://seuusuario.github.io/repo ## Uso para empresa 1. Escolha formato A4/A5 2. Upload em lote das fotos 3. Use template ou posicione manual 4. + Nova Página quando terminar 5. Exportar PDF Completo = álbum pronto pra gráfica ## Licença MIT - Uso comercial liberado
